# Export schema v1

UTF-8 JSONL, one event per line; every record has `schema: 1`, `kind`, and `stamp`. Reject unknown schema versions. Files are named `<session UUID>-<five-digit segment>.jsonl`. Chronology is file append order within a session, not lexical UUID ordering across sessions. Session manifests are `<UUID>-manifest.json`; export-level `manifest.json` identifies schema/redaction. Consumers must not merge pressed-key state across sessions, app changes, focus changes or boundaries.

`stamp.mono`: callback-receipt uptime in integer nanoseconds (CLOCK_UPTIME_RAW, excludes sleep). `stamp.continuous`: callback-receipt continuous monotonic nanoseconds (CLOCK_MONOTONIC_RAW, includes sleep). `stamp.wall`: Unix seconds, a Double, for wall-clock alignment only. Each event also carries `sourceTimestampNS` from CGEvent.timestamp, when present. Hold/down intervals use that source timestamp, or simulated receipt uptime in tests. Integer nanosecond representation does not imply nanosecond accuracy. Hardware scan, USB/Bluetooth polling, OS scheduling, event coalescing and source synthesis introduce latency/jitter; callback latency differs from source latency. Never subtract different clock domains. Wall time can jump; collection deadlines use the continuous clock.

Kinds: `key-down`, `key-up`, `modifier`, `mouse-down`, `mouse-up`, `scroll`, `motion`, `input-pause`, `app-change`, `boundary`. Optional fields are absent when unknown/disabled; absent never means zero:

- `app`: supported foreground bundle ID, only in allowed contexts. Excluded app identities are not stored.
- `keyCode`: macOS virtual key code (keyboard position dependent), not a USB hardware/device identifier. `modifiers`: CGEventFlags bitmask. `repeated`: system autorepeat indicator. Modifier transitions are observed flagsChanged records; modifier hold durations are not derived.
- `text`: up to 64 UTF-16 units of observed key-down characters, opt-in; suppressed for Command/Control/Fn shortcuts and non-ASCII-capable input sources. Never AX document/field values. `layout`: input source ID when available. Characters may be precomposition/layout-dependent, missing or truncated. They are not final document contents.
- `holdNS`: matched key/button release minus press, in source-clock nanoseconds. Repeated downs do not replace original press. Missing presses or focus boundaries produce no duration. `downIntervalNS`: consecutive nonrepeat key-down interval. `gapNS`: current down minus most recently observed up; this is NOT the full signed flight interval when the preceding press still overlaps. `overlap`: number of held nonrepeat keys before this down. The offline summary matches releases to compute full signed flight: next down minus preceding press's release; negative means overlap. No reconstruction across boundaries.
- `reason: correction-key`: observed Backspace or Forward Delete down; not proof of a semantic edit or number of removed characters. `input-pause.holdNS`: ≥2-second silence between observed input events in one eligible context.
- `button`: Quartz button number, left 0/right 1/others system-defined. `clickCount`: OS-provided click-state count; not a separate inferred click detector. A click is an observed down/up pair.
- `x`,`y`: Quartz global desktop coordinates in logical display points, origin at upper-left of main display, positive x right/y down; additional displays can have negative coordinates. No screenshots or window geometry are read.
- `dx`,`dy`: point-based Quartz horizontal/vertical scroll deltas, with OS sign, acceleration and device semantics retained. `continuousScroll` identifies continuous-device reports; not physical distance or a count of wheel notches. Motion is sampled at most 10Hz, intermediate positions discarded, never replayed or extrapolated.
- `title`: opt-in supported foreground window title, truncated to 256 characters. It may contain personal filenames.
- `boundary.reason`: checking, active, focus-change, sleep, locked, secure-input, excluded-app, unsupported-app/field, unknown-focus/field/app, focus-mismatch/race, permission-denied, paused, expired, tap-disabled, storage-error, quit/error. No arbitrary sensitive app/window contents are included in exclusion records.

Session manifest: schema, session UUID, createdWall, windowHours, elapsedSeconds, durationsSeconds (time by eligibility reason), state, droppedKnown, unknownLossPossible, textEnabled/titlesEnabled/motionEnabled, callbackCount/callbackTotalNS/callbackMaxNS, platform. `active` is time the safety gate considered the editor eligible, not a proof of loss-free hardware delivery. Sampling is approximately one second plus event-driven changes, with synchronous boundary notifications; focus transitions can race. Missed boundaries and OS event drops cannot be exhaustively counted. Known drops count tap disable notifications and failed record writes; unknown loss is always possible.

Timing-only/redacted export strips text, title, app, keyCode, modifiers, x/y and original session manifests. It retains timing, event categories, correction flags, scrolling and hold/overlap aggregates. It cannot provide key-pair flight statistics after identity removal. Redaction reduces sensitivity; patterns can remain identifying. Full export includes original manifests and must be treated as sensitive.
