# API and platform research — 2026-10-26

Observed development host: macOS 26.6.1 (25G76), arm64. Command Line Tools Swift 6.2.3; full installed Xcode 26.2 (17C52) supplies XCTest. This is environment inspection, not owner capture verification. App deployment target: macOS 13+, Swift 6 compiler using Swift 5 language mode; Apple silicon built locally. Intel/macOS 13–15 are source deployment targets, not tested hardware/OS combinations.

Official Apple sources consulted before API selection:

- [NSStatusItem](https://developer.apple.com/documentation/appkit/nsstatusitem): native system status bar item; `.accessory` and LSUIElement avoid a Dock-only app. macOS/user determines right-hand icon ordering.
- [CGEvent.tapCreate](https://developer.apple.com/documentation/coregraphics/cgevent/tapcreate(tap:place:options:eventsofinterest:callback:userinfo:)): listen-only annotated-session tap; no event mutation, filtering, posting or HID-device seizure. Key/mouse/scroll masks only; motion optional. Target PID must match the verified foreground editor; unavailable target IDs are rejected.
- [CGPreflightListenEventAccess](https://developer.apple.com/documentation/coregraphics/cgpreflightlisteneventaccess()) and [CGRequestListenEventAccess](https://developer.apple.com/documentation/coregraphics/cgrequestlisteneventaccess()): explicit Input Monitoring consent, no TCC edits. [Apple's Input Monitoring steps](https://support.apple.com/guide/mac-help/control-access-to-input-monitoring-on-mac-mchl4cedafb6/mac).
- [AXUIElement](https://developer.apple.com/documentation/applicationservices/axuielement): Accessibility consent for metadata-only foreground app/focused editor field role/subrole/enabled checks. No AXValue, selected text, document URLs or contents. App and systemwide focused PIDs must agree; AX errors/timeouts reject. Optional window title is separately disclosed.
- [Technical Note TN2150](https://developer.apple.com/library/archive/technotes/tn2150/_index.html): official archived explanation of Secure Event Input and IsSecureEventInputEnabled. App only checks it; never disables/bypasses it. Rechecked before persistence. This archived note is not a new universal sensitive-field detection guarantee.
- [CGEvent.timestamp](https://developer.apple.com/documentation/coregraphics/cgevent/timestamp): preserves source timestamp alongside callback clocks. Local Darwin `clock_gettime(3)` documentation confirms UPTIME_RAW excludes sleep and MONOTONIC_RAW includes it; no wall-clock subtraction for durations.
- [NSWorkspace sessionDidResignActiveNotification](https://developer.apple.com/documentation/appkit/nsworkspace/sessiondidresignactivenotification): session switch-out notification, not authoritative proof of screen-lock state. Workspace sleep/display sleep/wake and session changes are observed. Public CGSession on-console status, Secure Input, global AX focus and event target validation gate every persisted event. The optional `CGSSessionScreenIsLocked` dictionary entry is an additional release-dependent veto when present, not a documented lock-state contract. Missing session dictionary/global AX focus fails closed. Real lock transitions need owner qualification; no login/lock-screen support is claimed.
- [SMAppService.mainApp](https://developer.apple.com/documentation/servicemanagement/smappservice/mainapp) and [register](https://developer.apple.com/documentation/servicemanagement/smappservice/register()): opt-in main-app launch at login, subject to system approval. No helper, LaunchAgent/Daemon, watchdog or hidden persistence. Every process launch begins OFF.

No Apple API guarantees universal sensitive-field detection in arbitrary apps. To keep scope bounded, only TextEdit and Xcode editor text areas are supported. Password managers, browsers, terminals, login/System Settings and all other apps are excluded. Even supported editor files may be sensitive; owner Pause remains necessary. Input-source/IME/dead-key text is incomplete; no final-text reconstruction claim. Permission and lock behaviors are simulated in deterministic tests; the signed installed product must be qualified by its owner before personal collection.
