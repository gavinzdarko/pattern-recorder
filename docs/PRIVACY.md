# Local data handling

Only the owner may enable recording, after the on-device Start disclosure. Every new process starts OFF. Text, titles and sampled motion are independent runtime opt-ins and reset OFF on restart. Timing-only never writes event characters, but physical key identity can still reveal text; treat all raw recordings as sensitive.

App-supported contexts are deliberately narrow: TextEdit and Xcode AXTextArea editors, enabled field, no secure/unknown subrole, matching global AX focus/workspace PID and event-target PID. Unsupported apps, unknown focus/session, AX failures, secure input, session/display sleep, configured exclusions and protected fields fail closed. Built-in exclusions include password-manager/keychain/authentication app IDs and sensitive system apps; all non-supported app IDs are excluded even if not named. Owner exclusions can narrow coverage; they cannot expand support. Xcode source files or TextEdit notes can contain secrets. Universal sensitive-field detection does not exist: Pause before private work. The app never promises exact reconstruction of documents or reliable access to arbitrary app context.

No clipboard/pasteboard access, screenshots, camera, microphone, browser history, network interception, credentials harvesting, background document reads, remote control, telemetry, analytics, cloud/AI processing or uploads. The executable has no network client or dependency. It does not send recordings to GitHub. Login is opt-in through SMAppService.mainApp; no agents, daemons, privileged helpers or hidden persistence.

Data lives in `~/Library/Application Support/PatternRecorder/`, outside this checkout. Directory mode 0700 and files0600; ownership is checked and symbolic links rejected. No cryptographic encryption is added: FileVault, account security, backups and other software running as the owner are outside this boundary. Segments rotate at 8 MiB; combined app-managed JSON/JSONL payload is capped at 256 MiB (capture stops at capacity); temporary atomic manifest replacement can momentarily consume one extra small manifest. Nothing evicts recent data to keep capturing. Retention deletes files older than 14 days by file modification time on store open and once per minute while running, including OFF/paused if the directory already exists. When app is not running, retention cannot run. Wall-clock changes affect retention dates but not collection deadlines.

Pause removes the tap before closing files. Permission revocation is checked per event and once per second; permission prompts occur only after Start. A failed write or disabled tap stops collection with a visible status; no silent restart. Sleep/session resumes only when the same process remains explicitly enabled and the deadline has not elapsed. Process restart/login starts OFF.

Exports are user-initiated local copies in a new mode 0700 directory with0600 files. Destinations within a Git checkout and existing destinations are rejected. Full exports include text/titles if captured and carry a sensitive-data warning. Redacted export removes characters, title, app, physical key identity, modifiers, layout and x/y coordinates plus original manifests. It still contains behavior patterns; never assume anonymity. It does not attempt to detect every cloud-synced directory; choose a truly local destination.

Delete stops capture and deletes all app-managed JSON/JSONL files. Exported copies, backups, APFS snapshots, Spotlight indexing and SSD remnants need separate owner management; deletion is not secure erasure. No text-bearing diagnostic log is written by the app. A partial record can exist after I/O failure/process crash; export fails on invalid JSON instead of silently concealing corruption.

Public publishing policy: code/docs and explicitly synthetic fixtures only. `.gitignore` excludes recordings, exports, JSONL except the named synthetic fixture, logs, archives, build outputs and secrets. `scripts/audit.py` scans tracked paths and every reachable history blob before pushes; heuristic scanning is paired with human/agent content inspection, never represented as proof. Do not attach real recordings to issues, PRs or CI artifacts.
